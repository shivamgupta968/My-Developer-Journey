# Contact Management System

A responsive contact manager built with HTML, CSS, and vanilla JavaScript. Supports CRUD, search/filter, generated initials avatars, and JSON import/export. Data persists in browser localStorage.

## Run locally
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` with Live Server (recommended) or double-click the file.

PowerShell:
```powershell
cd "$HOME\\Downloads\\Contact-Management-System"
code .
```

## Features
- Create, view, edit, delete contacts
- Live search across contact fields and filters for email/phone
- Initials avatars with palette
- Import and export JSON
- localStorage persistence
- Responsive layout

## Tech: HTML5, CSS3, JavaScript ES6, localStorage, JSON
