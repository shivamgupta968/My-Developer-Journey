# Northstar Login System

A polished responsive login demo made with vanilla HTML, CSS, and JavaScript.

## Features
- Responsive login UI and post-login dashboard
- Email format validation
- Password minimum-length validation and strength meter
- Show/hide password toggle
- Remember-me demo persistence (localStorage); temporary session (sessionStorage)
- Demo password recovery confirmation
- Accessible labels, inline errors, and alert feedback
- No build step or dependencies required

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Demo sign in
Use any valid email address and a password of at least 8 characters. This is a front-end demo only; it does not connect to a server or provide real security/authentication.
