# Timeglass — Glass Morphism Digital Clock

A responsive digital and analog clock with a frosted-glass interface.

## Features
- Live digital clock with seconds
- 12-hour / 24-hour toggle
- Analog clock with moving hands
- Dark and light themes
- Automatic date, timezone, and UTC offset
- Responsive desktop and mobile layout
- No npm install or backend required

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `glass-morphism-digital-clock` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. With Live Server: right-click `index.html` → **Open with Live Server**.

## Windows PowerShell commands
Run these commands after downloading the ZIP to your Downloads folder:

```powershell
cd $HOME\Downloads
Expand-Archive .\glass-morphism-digital-clock.zip -DestinationPath "$HOME\Desktop" -Force
code "$HOME\Desktop\glass-morphism-digital-clock"
```

To open directly in your default browser:

```powershell
Start-Process "$HOME\Desktop\glass-morphism-digital-clock\index.html"
```
