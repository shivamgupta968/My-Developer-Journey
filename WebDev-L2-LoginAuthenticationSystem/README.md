# SecureSpace — Login Authentication System (Updated)

Oasis Infobyte Level 2 Task 4 — HTML, CSS and Vanilla JavaScript.

## Features
- Sign in and create-account interface
- Responsive desktop and mobile design
- Form validation, password visibility and strength indicator
- Demo account creation/sign-in using browser localStorage
- Successful login opens a developer welcome home page
- Developer-focused motivational message and learning cards
- Logout returns to the sign-in page

## Run
Open this folder in VS Code and open `index.html` with Live Server, or run:
```powershell
py -m http.server 5500
```
Then visit http://localhost:5500/index.html

## Security note
This is a frontend learning demo, not production authentication. Demo passwords are stored in localStorage and are NOT secure. Never enter real passwords or personal data. Production authentication requires a secure backend, password hashing, HTTPS, secure sessions and server-side validation.
