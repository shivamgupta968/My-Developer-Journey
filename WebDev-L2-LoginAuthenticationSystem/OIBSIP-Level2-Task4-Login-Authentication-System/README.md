# SecureSpace — Login Authentication System

Level 2 Task 4 project built with HTML5, CSS3 and Vanilla JavaScript.

## Features
- Sign in and create-account interface
- Responsive desktop and mobile design
- Email, name, password and confirm-password validation
- Password visibility toggle and strength indicator
- Terms checkbox and remember-me UI
- Demo account creation and sign-in using browser localStorage
- Forgot-password demo feedback

## Run using VS Code
1. Extract this ZIP.
2. Open the extracted project folder in VS Code.
3. Open `index.html`.
4. Right-click the file and select **Open with Live Server** (install the Live Server extension if needed). You can also open `index.html` directly in a browser.

## Security note
This is a frontend learning demo, NOT production authentication. It stores demo passwords in browser localStorage, which is not secure. Never enter real passwords or personal data. A real system needs a backend, HTTPS, server-side validation, password hashing (Argon2id/bcrypt), secure sessions/cookies, rate limiting and a secure password-reset process.

## Tech stack
HTML, CSS, Vanilla JavaScript, localStorage (demo only).
