# OIBSIP Web Development & Designing — Level 2 Task 2

## Tribute Page: Dr. A. P. J. Abdul Kalam

A responsive, editorial-style tribute page built with HTML5, CSS3 and vanilla JavaScript.

### Features
- Subject name and tagline in a prominent hero section
- Prominent portrait with source attribution
- Original biography content in four paragraphs
- Milestone timeline of key achievements
- Distinctive quote section
- Multiple section background colours
- Playfair Display serif headings and DM Sans body typography
- Responsive desktop, tablet and mobile layouts
- Smooth in-page navigation

### Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

### Deploy
Push the project files to the `main` branch of the OIBSIP GitHub repository, then enable GitHub Pages from the repository's Pages settings using `main` and `/ (root)`.
