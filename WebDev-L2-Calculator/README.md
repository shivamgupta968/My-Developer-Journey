# OIBSIP – Web Development & Designing – Level 2 – Task 1: Calculator

A responsive browser-based calculator built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication and division
- Decimal input, clear and backspace
- Sequential operator chaining
- Division-by-zero error handling
- Keyboard support
- CSS Grid button layout
- Event listeners (no inline `onclick`) and no `eval()`

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Try `5 + 3 × 2`, decimal calculations, backspace, and division by zero.

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript
